■ 卡片關玩法(三個卡片奇兵共用,改一筆 spec 就多一關)
  • 不會輸:答錯溫柔重試;step 三種 kind:info/question/order(沒有 match,配對改用 question/order)。
  • emoji 小劇場(scene):walk/lift/speak/flash/fall/rise/cycle/drop/pulse + caption 說話小字;
    進場從下方緩緩升起、選項加 1️⃣2️⃣3️⃣ 號碼、答對 ✨🎉。
  • 分數比賽:第一次答對 3 分/第二次 2/第三次以後 1(都有分);右上常駐⭐;結尾「🏆得勝!」+ 金句大畫面。
  • 單獨玩 ?demo=<key>(全螢幕淺底大字,投影用,右上 ⛶ 全螢幕鈕)——詳見新 skill card-flow-minigame。
  • 動作關(聖歌/反轉)比照摩西「撐住一個會下滑的值」/「閃避移動」,自成一格場景,嵌入白名單已加。

■ 兒童營現場(影響所有設計)
  • 我們有很多教室,每間都有電腦 + 投影機 → 可「分站輪流」:每間教室一台 PC+投影開一個奇兵
    (各奇兵都有獨立 ?demo=/?level= 入口 + .bat,天生支援分站)。或「大螢幕全隊玩」一人操作全場喊。
  • 小學生**不能用手機**;單機、鍵盤優先(↑↓/空白/方向鍵)、短局、大字、響亮音效、**全離線**、結算大畫面。
  • 分組計分:大廳「🏆 分組計分板」(localStorage)記各組分數;老師把卡片關得分加進該組做競賽。
  • 營會時間:約 2026 年 7 月初(距今約 3 週)。守住「綠色必交」即穩,做不完的關那天用實體團康補。

■ ⚠ 地雷（接手務必守）
  1. GitHub 是唯一真相;一律在 git 工作樹裡工作、文件跟程式一起 commit;zip 只是備援。動手前先確認在哪個分支。
  2. 戰爭/動作關別 push 約拿 main(會自動部署曝光);卡片奇兵文案未過牧者審別併 paul main(會自動部署)。
  3. .bat 純英文 ASCII + CRLF;啟動用 `npm run dev -- --open "/?demo=KEY"`;**別寫 Unix 的 >/dev/null,要 nul**。
  4. 卡片 spec 的 answer 不可越界(最常見致命錯)——過 game-content-validator / npm test。
  5. agape250 機的 vite build 偶爾無聲死掉(exit 127):先手動刪 dist/ 再 build;或重跑一次。約拿 npm run build 是逐檔複製不受影響。
  6. 約拿 level:7 摩西、8 紅海(預留)、9 聖歌、10 反轉。
