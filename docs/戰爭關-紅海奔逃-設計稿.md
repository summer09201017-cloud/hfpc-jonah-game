# 戰爭闖關 #2「紅海奔逃」單關設計稿

> 第一關(摩西舉手)驗證「戰爭動作關」成立後放行做這關。
> 經文:**出埃及記 14**(過紅海)。重用「跑酷/閃避」手感,但做成**自成一格的場景**(像 storm/moses),
> level === 8,**暫住約拿 repo 做原型**(驗證後與摩西一起搬進保羅)。

## 一句話玩法

法老的戰車從後追來,前面是紅海。先**站住等候神**(出 14:13),神分開紅海後,
**趁海分開、海牆倒數合攏前,跑過海床到對岸**;一路**跳過海床上的礁石/陷坑**,
被絆到就慢下來、追兵逼近;追兵追上=失敗,跑到對岸=海合攏淹沒追兵(過關)。

## 三個階段(self-contained 場景,phase 機械)

| phase | 內容 | 輸入 |
|---|---|---|
| `stand` | 站住等候:戰車在後、紅海在前,海**漸漸分開**(海牆升起)。出 14:13「你們只管站住,看耶和華…的救恩」。海全開後出現「舉杖」提示 | 海全開後**輕點/跳鍵=舉杖,衝過海床**(早點則顯示「站住,等候」不前進) |
| `cross` | 過海主玩法:世界向左捲(約拿固定 PLAYER.x),自動向前;**跳過海床障礙**;後方戰車(追兵)距離 `lead` 動態變化 | 輕點/跳=跳;絆到障礙=踉蹌變慢、追兵逼近 |
| `closing` | 抵達對岸:海牆合攏淹沒戰車(14:28),播放動畫→過關 | — |

## 重用 vs 新寫

| 重用(現成) | 新寫(這關成本) |
|---|---|
| `Player` 的跳躍/重力(`game.player.jump/update/onGround`) | `redsea.js` 場景 class(構造同 Storm/Moses) |
| `_prophet` 向量奔跑人形 | renderer `_drawRedSea`:分開的海牆、海床、戰車追兵、對岸、HUD |
| 遊戲迴圈 / win·gameOver / HUD bar / 嵌入契約 | 追兵 `lead` 動態 + 障礙跳判定 + 站住計時閘門 |

## 依靠值鉤子(出 14:13–14)

- **站住**:不能一開始就亂衝——要**等神分海**(海全開才衝)。信息:「耶和華必為你們爭戰,你們只管靜默,不要作聲。」
- **不是靠自己殺出重圍**:沒有攻擊鍵、打不到戰車;唯一的路是神開的海路。得救是**神施行的救恩**,人只管照著走。

## 數值(config `REDSEA`,全可調)

standTime(海分開的秒數)、runSpeed、goalDistance(海有多寬)、hazardGap(障礙間距)、
chaseGapStart/Max(追兵起始/最大領先)、chaseCloseOnHit(絆到一次追兵逼近量)、
gapRecoverPerSec(乾淨奔跑時拉開的速度)、stumbleTime(踉蹌變慢秒數)、closeTime(海合攏動畫)。

## 過關 / 失敗

- **過關**:跑到對岸(dist ≥ goalDistance)→ `closing` 海合攏 → `win()`。
- **失敗**:追兵追上(lead ≤ 0)→ `gameOver()`(動作關可重試)。

## 驗證閘門(headless 模擬,同摩西)

- 都不跳 → 一直絆到 → 追兵追上 → **敗**。
- 反應式好玩家(跳過障礙)→ 拉開追兵 → 到對岸 → **勝**。
- 站住階段太早衝 → 不前進(等海全開)。

## 嵌入契約

self-contained 場景、`ui` 注入、`embed` 旗標、結束走有嵌入分支的 win/gameOver、
HUD 兩端走 hudLabels;純 Canvas 關(像 1/2/4/7)→ NullUI 即可。level 8 加進 embedLevel 白名單與 boot 派發。
